# 💳 Simulador de Maquininha PagSeguro

Simulador web de terminal de pagamento — interface mobile-first que reproduz o fluxo de aprovação de transações do PagSeguro, direto no navegador.

## 🎯 O que é

Simulador visual de maquininha de cartão para uso em demonstrações, treinamentos ou estudos de UX de terminais de pagamento.

- Interface realista de terminal POS
- Fluxo completo: inserção de valor → processamento → aprovação
- Mobile-first, funciona em qualquer navegador
- Zero dependências — arquivo único

## 🚀 Como usar

1. Abra `index.html` diretamente no navegador
2. Nenhuma instalação necessária
